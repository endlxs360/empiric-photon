Cuando la respuesta de una IA tiene que alimentar un script o un documento, la prosa libre es un problema. Un Master Prompt bien estructurado convierte a Claude en una pieza predecible de tu flujo de trabajo.

1. Define el rol y la tarea en una frase

Empieza por lo esencial: quién es el modelo y qué debe producir. Una instrucción corta y concreta rinde más que un párrafo ambiguo.

2. Declara el esquema de salida

Describe cada campo, su tipo y los valores permitidos, e indica cuáles son obligatorios.

Eres un analista de contratos. Extrae los datos del texto
dentro de <datos> y responde SOLO con JSON válido:

{
  "resumen": "string, máximo 40 palabras",
  "puntos": ["string", "..."],
  "riesgo": "alto | medio | bajo"
}

3. Separa instrucciones y datos con etiquetas

Envuelve el contenido a procesar en etiquetas como <datos>. Así Claude distingue lo que debe obedecer de lo que debe analizar, y reduces errores cuando el texto de entrada contiene frases que parecen órdenes.

4. Añade un ejemplo

Un ejemplo completo de entrada y salida fija el formato mejor que cualquier descripción. Incluye uno que cubra un caso normal y, si puedes, otro con datos incompletos.

5. Valida con Python y reintenta

Nunca des por buena la respuesta sin comprobarla. Parsea el JSON, verifica los campos y, si falla, devuelve el error a Claude para que lo corrija.

import json

def parsear(respuesta: str) -> dict:
    datos = json.loads(respuesta)
    faltan = {"resumen", "puntos", "riesgo"} - datos.keys()
    if faltan:
        raise ValueError(f"Faltan campos: {faltan}")
    return datos

Limita los reintentos a dos o tres. Si el prompt está bien diseñado, casi todas las respuestas pasarán a la primera.

En resumen

Rol claro, esquema explícito, datos separados, un ejemplo y validación en código. Con esas cinco piezas, la salida de Claude deja de ser texto y pasa a ser un dato en el que puedes confiar.
