When an AI response has to feed a script or a document, free-form prose is a problem. A well-structured Master Prompt turns Claude into a predictable component of your workflow.

1. Define the role and the task in one sentence

Start with the essentials: who the model is and what it must produce. A short, concrete instruction outperforms an ambiguous paragraph.

2. Declare the output schema

Describe each field, its type and the allowed values, and state which ones are required.

You are a contract analyst. Extract the data from the text
inside <data> and reply ONLY with valid JSON:

{
  "summary": "string, maximum 40 words",
  "key_points": ["string", "..."],
  "risk": "high | medium | low"
}

3. Separate instructions and data with tags

Wrap the content to process in tags such as <data>. That way Claude can tell what it must obey from what it must analyse, and you reduce errors when the input text contains sentences that look like orders.

4. Add an example

A complete input and output example fixes the format better than any description. Include one that covers a normal case and, if you can, another with incomplete data.

5. Validate with Python and retry

Never take the response for granted without checking it. Parse the JSON, verify the fields and, if it fails, send the error back to Claude so it can correct it.

import json

def parse(response: str) -> dict:
    data = json.loads(response)
    missing = {"summary", "key_points", "risk"} - data.keys()
    if missing:
        raise ValueError(f"Missing fields: {missing}")
    return data

Limit retries to two or three. If the prompt is well designed, almost every response will pass on the first attempt.

In summary

A clear role, an explicit schema, separated data, one example and validation in code. With those five pieces, Claude's output stops being text and becomes data you can rely on.
